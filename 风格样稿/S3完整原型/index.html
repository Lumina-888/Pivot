📊 概览P7统计卡/解析队列/趋势 📄 文档管理P8上传/解析状态/重试/删除 👥 用户管理P9新建/角色/停用/重置 📜 审计日志P10全留痕/提问命中展开

推荐浏览路径（含联动演示）

1. 登录（任意输入）→ 2. 首页点「人事制度」→ 3. 知识库点「考勤管理制度 v3」→ 4. 文档详情点「针对本文提问」→ 5. 对话页看到「已引用文档」chip → 6. 输入任意问题回车看分发轨迹 → 7. 点引用 [1] 弹证据抽屉 → 8. 抽屉内「跳转原文」返回文档详情定位高亮。
另：首页 Hero 搜索框切到「问 AI」输入问题 → 自动跳对话带入问题；顶栏搜索（Ctrl+K）带关键词跳搜索结果页。
数据与交互均为演示：对话回复为本地模拟；文件解析/上传/删除仅做界面状态演示。
正式开发：Next.js + shadcn/ui，按 `s3.css` 设计令牌与 `common.js` 交互组件落地；页面 ↔ 规格文档对照详见 README.md。
