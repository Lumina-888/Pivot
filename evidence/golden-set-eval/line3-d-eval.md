# 线三 D 相关性门禁标定与复跑证据

- 日期：2026-10-23
- 状态：标定与四组真实路径复跑已完成。候选值待 Owner 冻结（DR-010），生产默认装配未改。
- 口径：政策尺寸为测试值（dense_k 为 8、bm25_k 为 8、rrf_k 为 60、evidence_limit 为 5）。不冻结 TBD-P0，不标 GATE-P0 verified。
- 前置：本轮在稠密腿修复（FR-RAG-009，PR #32）之后的真实全链上进行。此前各轮评测的稠密腿均未生效，见 default-path-eval.md 与 live-path-eval.md 的更正节。

## 1 方法

第一步是分数标定。对两套集共 240 例逐例采集三路分数：稠密余弦（真实 bge-m3，经缓存嵌入）、BM25（生产实现）、重排分数（真实 bge-reranker-v2-m3，对全部融合候选打分）。标定复刻基线与 ND-P0-03 记录的差异正是稠密腿缺陷的发现路径，见 PR #32。

第二步是离线模拟。候选配置经生产 RetrievalService 代码本体（静态分数提供者注入）跑全量网格，筛出候选值与稳健区间。模拟与真实路径在主组上逐项一致（同为 108 / 120，分层全同）。

第三步是真实路径复跑。运行器 ops/run_live_path_eval.py 本轮新增门禁参数（--rerank-floor、--dense-floor、--rerank-pool、--per-doc-cap），四组口径见 §3。

第四步是智能体层代理核查，见 §5。

## 2 候选值与稳健区间

| 参数 | 候选值 | 依据 |
| --- | --- | --- |
| rerank_floor | 0.3 | 企业集真答案语块的重排分数最低 0.948；拒答诱饵多在 0.3 以下。企业集结果对 0.05 至 0.7 全区间不敏感，0.3 居中留裕量 |
| dense_floor | 0.65 | 稠密救援带为 0.58 至 0.66：低于 0.58 时合成集范围层救援不足，高于 0.66 无额外收益。企业集拒答候选的稠密最高分低于 0.55，不被误救 |
| rerank_pool | 12 | 与 20 的结果一致，取小者控制重排成本。解耦前为 5（与 evidence_limit 绑定） |
| per_doc_cap | 不设 | 模拟中 cap 为 2 使企业集从 108 降到 97：多例合法地需要同文档 3 块以上语块。配额机制保留，数值不启用 |

候选值的语义：候选通过门禁，当且仅当其任一已测信号达标（重排分数不低于 rerank_floor，或稠密分数不低于 dense_floor）。无信号可测的候选按 ADR-014 的降级规则放行。

## 4 两个结构性残余

### 4.1 企业集 unauthorized 层（0 / 12）

该层问题是摘录编号探针（如「摘录编号 0900 无权限摘录」）。受限语块从未被返回，泄漏为零，授权过滤完好。失败形态是：同编号的已授权语块（补充段与正文段）被返回，它们的重排分数为 0.946 至 0.96，与真答案语块的分数带（最低 0.948）完全交叠。编号词元的共享使重排器给出高分，任何下限都无法在不误杀真答案的前提下过滤它们。

定性：这不是相关性问题，而是授权相邻内容的处置问题。受限内容本身不在返回结果中，由这些语块支撑的答案不包含受限信息。是否拒答应由答案层判定（证据是否真正支撑所问内容），不属检索层门禁的职责。本层结论登记为：检索层不可修复，转答案层议题。

### 4.2 合成集 multi_span 层（带重排 0 / 12）

互补语块在融合阶段已被召回（稠密与 BM25 均在前列），但在重排后被挤出证据上限。合成集语块是词元串文本，重排器对其打分近乎噪声（多数在 0.04 以下），重排顺序不可用。企业集同层在真实文本上是 12 / 12，说明机制在可读文本上成立。该层失败是合成集的构造产物，不构成生产风险证据；其回归价值由不带重排组与企业集承担。

## 5 智能体层代理核查

把 Agent Golden Set 的 9 个场景问题送入同一门禁漏斗（语料为夹具 8 块，受限块 syn-bal-1 按授权对 employee_wang 不可见），对照门禁关与候选值两口径：

- 可答场景（ag-001、002、003、004、007、009）：候选口径下关键证据不变，召回无损。
- ag-005（婚假）与 ag-006（个人余额）：证据从 5 块压到 1 块（reg-c2，年休假天数档位表），未归零。该语块与问题同属休假天数话题，两路分数均达标，门禁没有理由过滤。
- ag-006 在 05-D 的泄漏形态（模型读到受限块并答出余额与工号）在生产授权下不可复现：该块对提问者根本不进入候选集。

结论：智能体层的端到端拒答不能只靠检索门禁。证据收窄降低了误答面，但 ag-005、ag-006 是否翻正取决于答案层（收尾器对证据是否支撑问题的判定）。这与 §4.1 是同一议题：答案层相关性判定。建议单独立项，不在本片扩张。05-D 的 live 复核仍待业务复核集（ND-P0-01-A）到位后与该议题合并评估。

## 6 结论与 DR-010 候选登记

验收硬线逐项对账：

- 企业集内容层 96 / 96 不回退：达成。
- no_answer 两套集全过且泄漏清零：达成（12 / 12、12 / 12，泄漏 0）。
- unauthorized 全过：未达成。企业集 0 / 12，根因见 §4.1，已定性为答案层议题；合成集 12 / 12。受限内容零泄漏达成。
- 合成集带重排回 120：未达成（108），缺口仅 multi_span，根因见 §4.2。
- ag-006 翻正：检索层未翻正，证据由 5 块收窄到 1 块，受限块泄漏路径已由授权消除；端到端翻正待答案层议题。

DR-010 候选登记（待 Owner 冻结，生产默认装配暂不改动）：rerank_floor 为 0.3，dense_floor 为 0.65，rerank_pool 为 12，per_doc_cap 不启用。冻结动作包含把候选值接进生产装配（bootstrap 的 RetrievalPolicy 构造）与复跑本轮主组确认，属独立小片。
