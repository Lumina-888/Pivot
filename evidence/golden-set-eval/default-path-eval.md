# 默认检索路径 Golden Set 实测报告

本报告记录 L4 默认切换后，LlamaIndex 检索路径在两套 Golden Set 上的实测结果。测量对象是生产默认路径：LlamaIndexRetriever 加 Qdrant 持久索引（LlamaQdrantIndex），索引构建、再水化与检索均为生产代码，Qdrant 客户端为内存模式。GATE-P0-002 仍为 unverified，本报告不改变该状态。

## 2026-10-23 更正与复测

线三 D 标定复刻基线时发现：默认路径的稠密通道自 LlamaIndex 集成以来一直失效。`_LlamaDense` 经 `index.as_retriever()` 传 `node_ids`，在 llama-index-core 0.11.23 下抛 TypeError，异常被降级语义吞掉，检索实际只有 BM25 一条腿。本报告 2026-10-21 的原始数字（合成 120 / 120、企业 96 / 120、标注命中率 1.0）均在该状态下测得，测的是 BM25 单腿行为，「稠密与 BM25 通道仍会返回词面最接近的块」一说中的稠密部分不成立。拒答根因（检索层无相关性下限）的定性结论不受影响。

缺陷已修复（FR-RAG-009：改走直接构造 VectorIndexRetriever；稠密候选下界由 −1.0 改为 0.0，仅正相似度进入融合；稠密腿输出按分数与 chunk_id 确定性排序，消除 ANN 遍历顺序带来的融合名次波动）。下文 §2、§3 已替换为修复后的复测数字（受控词袋嵌入口径）。词袋嵌入的相似度是词面重叠而非语义，企业集上它对融合的扰动大于真实嵌入；生产嵌入（bge-m3）下的数字以线三 D 的 live 复跑为准，不以本节数字为准。

复测数字的稳定性说明：Qdrant 的近似检索在 top-k 边界上存在固有的集合成员波动，同一提交在 CI 两次运行中企业集标注命中出现 76 与 75 两值。表中数字为单次测量值；锁定测试对企业集总量按区间锁定（命中 74 至 78、通过 65 至 69、泄漏不超过 10），结构性断言（拒答两层为 0）仍取精确值。

## 1 测量方法

- 脚手架：tests/integration/pipeline/default_path_eval.py。语料与授权事实由数据集记录派生，与 L2 对比脚手架同口径。
- 运行命令：`python ops/run_default_path_eval.py`（合成集）与 `python ops/run_default_path_eval.py --enterprise`（企业集）。退出码在有用例未通过时期望为 1。
- 检索策略：dense_k 与 bm25_k 均为 8，rrf_k 为 60，证据上限 5 条。BM25 的 k1 为 1.2，b 为 0.75。稠密通道分数下界为 0.0，即仅正相似度进入融合，与生产装配一致（2026-10-23 前为 −1.0，且稠密通道实际失效，见更正节）。
- 嵌入器：受控词袋嵌入（BowEmbedder，维度 256），与 L2 对比脚手架相同。它按词元重叠产生向量，不代表真实语义嵌入的效果。
- 判定语义：与 Golden Set 既有评测一致。拒答用例须结果为空才通过；标注用例须期望块全部出现才通过；禁止块出现在证据中记为泄漏并判失败。
- 版本冲突期望不在检索层评分：问答级检索结果不携带冲突信号，该分支由编排器负责。本报告对这 12 例只按块期望评分，并单独计数。

以上策略数值与嵌入器均为测试值，不是生产设置，也不冻结 TBD-P0。

## 2 合成集 v0.2 结果

数据集为 golden-set-retrieval-v0.2-synthetic，120 例，语料 108 块。

| 指标 | 结果 |
| --- | --- |
| 用例通过 | 94 / 120 |
| 标注命中率 | 1.0（标注命中 108 / 108） |
| 禁止块泄漏 | 2 |
| 分层通过 | fact、parameter、multi_span、distractor、parse_failure、prompt_injection、version_conflict 各 12 / 12；document_scope 10 / 12；no_answer、unauthorized 各 0 / 12 |

内容类用例的期望块全部命中（命中率 1.0）。失败集中在拒答两层与 document_scope 两例：稠密通道恢复后，拒答问题同样返回最近邻语块，与企业集的失败同源（无相关性下限）。泄漏 2 块出在 gs_no_answer_12，其禁止块被稠密通道召回。2026-10-21 的 120 / 120 是稠密失效、BM25 单腿下的结果，已被本节取代。

## 3 企业集 v0.3 结果

数据集为 golden-set-retrieval-v0.3-enterprise，120 例，语料 612 块。数据是人工标注的脱敏摘录。

| 层 | 通过 | 标注命中率 |
| --- | --- | --- |
| fact | 7 / 12 | 7 / 12 |
| parameter | 6 / 12 | 6 / 12 |
| multi_span | 12 / 12 | 1.0 |
| distractor | 4 / 12 | 4 / 12 |
| document_scope | 12 / 12 | — |
| parse_failure | 12 / 12 | 1.0 |
| prompt_injection | 12 / 12 | 1.0 |
| version_conflict | 2 / 12 | 11 / 24（仅按块期望评分） |
| no_answer | 0 / 12 | — |
| unauthorized | 0 / 12 | — |
| 合计 | 67 / 120 | 0.70（76 / 108） |

失败分两类。拒答两层 24 例与既有定性一致（无相关性下限），泄漏共 8 块。内容层的下降是受控口径特有的：词袋嵌入按词面重叠产生相似度，企业集真实改写的文本上，稠密通道把词面相近但无关的语块送进融合，挤出标注语块。该扰动幅度取决于嵌入的相似度质量，不代表生产嵌入（bge-m3）下的行为；2026-10-21 的 96 / 120 与命中率 1.0 是 BM25 单腿结果，已被本节取代。

## 4 拒答层的失败定性

失败的根因是检索层没有相关性下限。问题在语料中无答案或提问者无权查看答案时，检索通道仍会返回最接近的块并补足到证据上限，于是结果不为空。（2026-10-23 更正：原测时稠密通道失效，该行为当时只有 BM25 通道在产生；稠密恢复后，两条通道都会产生此行为，合成集的拒答问题也随之暴露。）

这不是 LlamaIndex 路径独有的缺陷：

- 自研路径在生产装配下同样不做稠密分数过滤，SPEC 的检索阈值仍是 TBD-P0，两条路径都没有可用的下限。
- 既有 Fake Keyword 口径在企业集上 120 / 120 通过，是因为整词组精确匹配对改写问题一律返回空，属于保守假象，不能作为拒答能力的证据。

生产系统中的拒答由问答层的答案核验承担：证据不足以支撑答案时由编排器拒答。本报告只测检索层，不测问答层，因此拒答层的结论是「检索层单独不保证拒答」，不是「系统不会拒答」。问答层与真实模型下的端到端拒答率属于 ND-AGENT-05 的 live 评测范围，尚未执行。

## 5 结论与可引用口径

- 2026-10-21 的原结论（命中率 1.0、内容层全过）已失效：那是稠密通道失效、BM25 单腿下的测量。
- 修复后受控口径的现状：合成集内容召回仍完整（命中率 1.0），拒答两层在两套集上均未通过，企业集内容层受词袋稠密扰动下降到 67 / 120。已知限制仍是检索层无相关性下限，处置已立项为 ADR-014 相关性门禁，数值标定在线三 D 以真实嵌入进行。
- 对外引用本报告数字时必须带限定：数据为合成集与脱敏摘录，嵌入为受控词袋嵌入，策略数值为测试值。可以表述为「在 Golden Set 受控口径上，默认检索路径的合成集标注命中率为 1.0；检索层尚无相关性下限，拒答层未通过，修复已立项」。不得再引用「命中率 1.0、内容类全部通过」描述企业集，不得表述为真实业务准确率或生产拒答率。
