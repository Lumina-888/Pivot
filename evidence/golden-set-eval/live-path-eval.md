- 密钥经连接器代理注入，评测代码不接触明文。语料向量按文本哈希本地缓存，重跑不重复计费。
- 本票同时修复一处接线遗漏：默认问答路径此前未接重排。变更记录见 `progress/changes/20261022-M04-llama-rerank-wiring.md`。分组回归 2739 项全绿。

## 企业脱敏集 v0.3 结果（120 例）

三组通过数相同：受控基线 96、live 无重排 96、live 带重排 96。标注命中率三组均为 1.0。禁止块泄漏三组均为 10。

- 内容八层：三组均为每层 12 过 12。
- 拒答两层：三组均为 no_answer 0 过 12、unauthorized 0 过 12。
- 逐例对比：live 无重排与受控基线的命中清单 120 例全部同序一致。本语料上 BM25 主导明显，换嵌入器不改变融合结果。
- 重排影响：101 例的命中清单顺序发生变化，但通过与否零翻转。document_scope 十二例为范围拒答，三组均返回空，不触发重排调用（重排实测 108 次）。

## DR-002 对比结论

拒答失败与嵌入模型无关。受控词袋与真实 bge-m3 的分数分布完全不同，拒答两层却以相同形态全灭，泄漏数同为 10。根因仍是检索层没有相关性下限：无答案问题照样返回最近邻。修复方向是分数下限机制，属 DR-010 阈值冻结与后续切片，本票不下结论。

## 合成集 v0.2 结果（120 例）

- live 无重排：120 过 120，标注命中率 1.0，泄漏 0。与受控基线一致。
- live 带重排：108 过 120，标注命中率 0.889，泄漏 0。十二个失败全部出在多跨度层（12 过 0），其余九层全过。
- 失败形态一致：每例都丢失同一文档的互补语块（如 chk_leave_a_01），前五被另一文档的同主题语块占满。重排按单块相关性打分，不保多文档覆盖，融合阶段已召回的互补证据在重排后被系统性挤出。
- 企业集多跨度层在带重排时未出现翻转（12 过 12）。两套语料的块长与主题分布不同，该风险在合成集上先暴露。

结论：全链开启重排不是免费的。是否启用、候选池大小与多文档配额属 DR-002 / DR-010 决策，本票只提供证据，不拍板。
