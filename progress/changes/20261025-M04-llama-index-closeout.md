# ADR-021：LlamaIndex 集成收口

- 状态：已接受；Owner 2026-10-25 批准。
- Accountable：M04。
- 基线：main（ADR-020 已落 main）。
- 需求：L1 至 L4 决策收口。
- 依据：ADR-020；ADR-016；ADR-018。

## 背景

L1 至 L4 已全部落 main。L1 接索引构建器与后端开关。L2 做双路径对比。L3 切 Qdrant 持久集合。L4 把默认后端切为 llama。ADR-020 删原生问答路径。问答至此只剩 llama。本稿收口四片决策。后续改动另立 ADR，不改本稿结论。

## 决策 D1 终局形态

问答只走 LlamaIndex。LangGraph 只管流程。流程是 decide、execute_tools、finalize 三步。检索不由图层做。自研 RetrievalService 只留给文档搜索。搜索的 dense 腿仍是 vector.py。搜索迁 llama 另立单，不在本稿范围。

## 决策 D2 后端字段

PIVOT_RETRIEVAL_BACKEND 字段保留。字段只认 llama。其他值启动期报错。报错文案指 ADR-020。显式后端字段已删。删字段见 ADR-020。开关不再是切换手段。开关只剩 stale 配置守卫。

## 决策 D3 集合形态

Qdrant 按库分集合。集合名是原生名加库后缀。公共库后缀是 pub。部门库后缀是部门编号。项目库后缀是项目编号。默认文件夹复用库集合。受限文件夹另建集合。旧单集合不再打开。旧单集合不再校验。旧单集合不再删除。旧单集合留待运维核实后手动删除。

## 决策 D4 授权复核

检索时 authorize 做实时复核。复核三项：删除态、当前态、库可见性。三项任一不符即拒绝。拒绝按不存在处理。external_llm_allowed 不在复核项内。该标志在构建时 baked。版本行原地改标志后要到对账才更新。改标志场景罕见。新版本走入库同步自然带过去。该残留记为已知项，不在本稿修。

## 决策 D5 双路径对比结论

L2 原行为等价结论已作废。作废原因是 dense 腿失效。失效期间检索实际为 BM25 单腿。B0 修复后已重测。重测 diff 为 none 22、order 0、set 98。两路内容召回等价。标注命中率同为 1.0。拒答差异由无相关性下限解释。下限问题由 ADR-014 门禁承接。答案层判定由 ADR-015 承接。本稿不再保留双路径对比口径。

## 决策 D6 依赖钉死

三个包钉死主依赖。llama-index-core 是 0.11.23。llama-index-vector-stores-qdrant 是 0.3.3。qdrant-client 是 1.12.2。教训是依赖兼容性验证必须包含全新解析。旧解析通过不等于新解析通过。后续升级须重跑全新解析验证。

## 决策 D7 回滚取消

native 回滚选项已取消。取消见 ADR-020。L4 曾保留一个发布周期作回滚。保留期已结束。回滚代码已删。回滚测试已删。切换说明已改写。切换说明只讲 llama-only 形态。

## 未采纳方案

保留原生路径作备用（缺陷仍在，维护两路成本高）。恢复后端开关切换（双路径已证明难维护）。搜索同批迁 llama（搜索迁 llama 另立单，分批走更稳）。
