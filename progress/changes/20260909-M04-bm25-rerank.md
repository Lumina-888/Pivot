# 变更申请：M04 stdlib BM25 与可注入 rerank

- **日期**：2026-09-09
- **申请人**：Wave 3 主线会话（M04 BM25 实现 + M11 composition root 可选接线）
- **背景**：dense 已消费 Qdrant；BM25 仍为 `KeywordRetriever`（空 corpus 不贡献命中）；rerank 未接线。SPEC FR-RAG-001 默认 dense+BM25→RRF→rerank；中文分词、RRF、rerank 阈值仍为 `TBD-P0`。禁止引入 jieba / bge 模型当冻结默认；不得把 Fake 标成 `GATE-P0-002` verified。
- **原契约/现状**：
  - `Retriever` / `Reranker` 端口已冻结；BM25 与 dense 均为 Keyword Fake；
  - composition root 的 bm25 为 `KeywordRetriever(())`；`reranker=None`；
  - 无 BM25 IDF/长度归一；无注入 tokenizer。
- **拟变更内容**（本切片）：
  - M04 增加 `SimpleLexTokenizer`（CJK 单字 + 拉丁/数字词，**不是** jieba）与 `Bm25Retriever`（stdlib BM25；`k1`/`b` 构造注入，`k` 来自调用方）；
  - `Bm25Retriever.add` 可增量建索引并 `resolve` chunk，供空 corpus 的 `retrieve` 水合；
  - 可选 `Bm25Reranker`（对候选文本用同一套注入参数打分）与既有 `OverlapReranker`；**不是** `bge-reranker-v2-m3`；
  - M11：`PIVOT_BM25_K1` 与 `PIVOT_BM25_B` 同时注入才改接 `Bm25Retriever`，缺一失败闭环；未注入则保持 Keyword（兼容既有 runtime 测试）；
  - `PIVOT_RERANK=none|overlap|bm25`（默认 none）；`bm25` 时必须已注入 k1/b；
  - **不** 新增 pyproject 依赖；**不** 冻结 k1/b/分词/rerank 阈值/top-50；**不** 把 `GATE-P0-002` 标 verified。
- **影响模块**：M04（tokenize/bm25、单元测试）；M11（settings/bootstrap、pipeline 测试、证据）；M00（MODULE_SPEC §11 现状一句）。
- **兼容方案**：未设 BM25 参数时 runtime 行为不变；既有 Keyword 单元与 Golden Set 不变。
- **测试 ID**：`test_FR_RAG_001_bm25_ranks_by_idf_not_raw_count`、`test_FR_RAG_001_bm25_uses_injected_k_and_params`、`test_FR_RAG_001_bm25_does_not_freeze_tokenizer`、`test_FR_RAG_004_bm25_failure_falls_back_to_dense`、`test_FR_RAG_001_bm25_rerank_reorders_candidates`、`test_NFR_OBS_runtime_bm25_requires_both_params`、`test_FR_RAG_001_runtime_bm25_retrieve_after_add`、`test_GATE_P0_002_not_verified_by_bm25_rerank`。
- **是否触发 ADR**：否（不改变状态机、权限、引用/删除语义；不冻结 TBD-P0 分词/阈值；不引入供应商模型）。
- **审核结果**：2026-09-09 Wave 3 主线会话 **批准**。
