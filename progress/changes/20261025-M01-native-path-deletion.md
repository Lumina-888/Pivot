# ADR-020：删除原生问答路径，问答只留 LlamaIndex

- 状态：已接受；Owner 2026-10-25 批准（修正范围同日批准）。
- 范围：M01、M04 的问答装配与测试。
- 依据：SPEC 附录 B.1 错误包络；ADR-010、ADR-014。

## 背景

默认问答已切 LlamaIndex。原生问答桥有过期证据标志缺陷。搜索仍走自研服务。桥与搜索服务共用服务实例。测试已有内存 Qdrant 客户端惯例。

## 决定

删除问答桥与问答原生兜底。问答无 Qdrant 时装配直接报错。搜索服务与 vector.py 保留。后端字段只认 llama，旧配置报错。测试改走 qdrant 内存客户端。开发用 Compose 的 Qdrant。CI 不加服务（测试不连真实服务）。

## 影响

生产无影响（已是 llama）。内存模式问答直接报错，不再悄悄走老路。搜索不受影响。回滚选项取消（native 已删）。

## 未采纳方案

只关开关（桥还在，缺陷还在）。全删搜索服务（搜索迁 llama 另立单）。测试连真实 Qdrant 服务（内存客户端已够用）。
