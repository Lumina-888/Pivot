## 交付清单
- [x] 可插拔解析器：PDF 启发式 + OOXML 标准库（docx/pptx/xlsx）。
- [x] 错误码：加密/损坏/空文本/扫描件/部分页失败。
- [x] 分块器：locator、title_path、字符偏移、文本 hash；窗口由 `ChunkingPolicy` 注入。
- [x] Fake Embedding 与维度校验；失败不发布索引代次。
- [x] 索引代次 building → published 原子发布；payload 含 `version_id + chunk_id`。
- [x] `IndexPublisher` 可注入 `VectorStore`；`publish` 前 `upsert`；缺 `document_id` 或 upsert 失败不 published。
- [x] Worker 输出 `ok/insufficient/failed` 信封；重复 `message_id` 幂等。
- [x] 隔离临时目录；无真实供应商密钥。
- [x] `DocumentIngestRunner`：HTTP/runtime 可调用既有 IngestWorker。
- [x] `IngestQueueConsumer` 只消费 parse 队列。
- [x] `CeleryIngestSubmitter`：optional extra `celery`；parse/online 隔离；eager 任务可调用既有 runner 并看见 PG version/task。
- [x] `python -m pivot_worker` 启动 `/healthz` + Celery worker（只监听 parse；broker 注入）。
- [x] `assemble_ingest_runtime`：worker 装配共享 PG 事实 + MinIO 对象；拒绝 memory 存储/对象。
- [x] `assemble_ingest_runtime`：`PIVOT_VECTOR_STORE=qdrant` 时装配 `IndexPublisher` + 注入维数的 Hashing embedder。
- [x] `PIVOT_EMBEDDING=http` 时 ingest 装配与检索同形的 `HttpQueryEmbedder`；失败不 published。
- [x] `PIVOT_PARSER=mineru` 时装配注入云 API 的 `MinerUCloudParser`（CI Fake HTTP；缺省仍启发式/stdlib）。
- [x] `worker[parse]` extra：PyMuPDF / python-docx / python-pptx / openpyxl；`PIVOT_PARSER=native` 装配真实库；缺 extra 失败闭环。
