## 确认的费用原则

- 所有收费路径先以可信最大费用预留额度，再派发；返回后按同一 attempt 幂等结算，不仅在事后检查已记录支出。
- 输入 Prompt 重写、Agent、Finalizer、模型 Verifier、收费 Embedding/Rerank 及重试/主备调用共用同一 Run 累计账本，恢复不清零。
- 费用上界覆盖可能计费的输入、可强制输出上限、reasoning 和适用的固定/缓存/失败收费类别；无法确定可靠有限上界则不派发该收费操作。
- unknown 用量不记零，保留预留并对账；上界或账本不可验证时停止新收费调用。取消/超时不被视为撤销已发生的费用。
- 实际超过预留时如实记录，不裁账、不再派发；设计控制的是基于已核实计价/用量上界的请求准入，不承诺供应商账单 exactly-once、退款或无条件绝对零超额。
- 费用耗尽不绕过授权、外发、取消或全量答案支持校验，不发布未验证答案。
