## 5. 其他意见及优先级

**实施优先级**（Owner 确认）：
1. **第一优先**：02-A/B/C - 核心 Agent 能力，必须完成才能答辩
2. **第二优先**：03-A - 恢复机制，展示系统健壮性
3. **第三优先**：04-A - 持久化，如时间允许实施
4. **后续优先**：05-A/B/C/D - 真实模型全面测试和优化

**风险控制**：
- 严格控制 API 调用费用，单次实验不超过 100 元
- 优先使用 Fake 模型完成基础功能，真实 API 仅用于关键验证
- 如遇技术困难，保证核心演示功能可用，其他功能可作为"设计但未完全实现"展示

**毕业答辩准备**：
- 重点展示：Agent 工具循环、观察驱动决策、证据追踪、安全控制
- 架构图和设计文档准备完整，即使部分功能未实现也能展示设计思路
- 准备 Demo 数据和演示脚本

需要改变需求、安全/权限、状态机、引用/删除或模型策略时，仍须登记相应变更/ADR。
