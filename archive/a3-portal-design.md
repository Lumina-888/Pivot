## 0. 设计原则（这三点决定所有页面）

1. **逛 + 问并举**：员工既能像逛维基一样浏览文档库，也能随时切换到对话问答；两件事互不打断。
2. **溯源是产品心脏**：任何 AI 回答都必须能"看到证据"，证据面板是对话页的常驻组件，不是可选项。
3. **MVP 可裁剪**：页面清单按 MVP/V2 标注；进度吃紧时先砍"逛"的复杂功能（收藏/热门/页内高亮），保"问 + 溯源"。


- 检索：BM25 关键词 + 语义向量混合（复用后端检索服务），结果带**命中上下文高亮摘要**；
- 筛选：空间/类型/标签；
- **无结果或结果不满意时**，底部引导"直接问 AI" → 跳对话页自动携带该问题——**搜索即问 AI 的漏斗**，这是门户"逛+问"一体化的关键衔接；
- MVP 不做：搜索建议、搜索历史（V2 加历史本地留痕）。

## 4. 关键交互流程（三条主线）

**① 逛 → 查 → 读**
首页点空间卡片 → 知识库列表（筛选）→ 文档详情 → 内嵌预览/下载。

**② 搜 → 问（漏斗衔接）**
任意页全局搜索 → 结果页 → 不满意的结果 → "直接问 AI" → 对话页自动带问题 → 答案+证据面板。

**③ 读 → 提问（单文档精准问答）**
文档详情 → "针对本文提问" → 对话页 @该文档（仅检索该文档）→ 高准确率答案。

入口 ②③ 是为了解决"大知识库答不准"的两个天然场景：**不知道有没有先搜**、**已经知道文档就针对它问**——MVP 就把这两条链路打通。

## 5. MVP 页面范围（定稿：10 页）

前台 6 页：登录 · 首页 · 知识库列表 · 文档详情 · 全局搜索 · 对话
后台 4 页：概览 · 文档管理 · 用户管理 · 审计日志

> 砍清单预案：若排期紧张，依次砍——① 全局搜索页（顶栏搜索合并进知识库列表）② 首页"最近更新"改为纯列表 ③ 后台合并为单页（统计+上传+用户+审计折叠）。**对话页 + 证据面板永不动。**

## 7. 视觉风格定稿：S3 商务蓝灰（交互增强版）

> 样稿文件：`风格样稿\S3-商务蓝灰.html`（同目录保留 S1/S2/S4/S5/S6 备选）。风格影响"颜色/圆角/密度/动效"，不影响本文件确定的页面结构与功能。

### 7.1 设计令牌（Design Tokens，正式开发时落为 CSS 变量）

| Token | 值 | 用途 |
|---|---|---|
| bg | `#f1f5f9` | 页面底 |
| surface | `#ffffff` | 卡片/面板 |
| border | `#dbe2ea` / `#edf1f6` | 边框/内分隔 |
| head | `#234060` | 顶栏深蓝（唯一深色块） |
| accent / accent-2 | `#1d4ed8` / `#3b82f6` | 主操作 / 悬停与渐变 |
| soft / hover | `#e8eef5` / `#f1f5f9` | 选中底色 / 悬停底色 |
| text / muted | `#1e293b` / `#64748b` | 正文 / 次要 |
| ok / danger | `#16a34a` / `#dc2626` | 成功 / 危险 |
| radius | 8px（卡片）/ 5~6px（控件） | 圆角 |
| 动效 | 150~250ms + `cubic-bezier(.25,.8,.3,1)` | 统一缓动曲线 |

### 7.2 交互规范（已确认的反馈标准）

- **导航**：下划线渐变滑动生长（hover 生长 / active 常驻）；当前页高亮；
- **卡片（空间/文档）**：hover 上浮 3px + 投影 + 左侧色条生长；按下 `scale(.985)`；次级元素（箭头/徽章反色）滑出呼应；
- **按钮**：hover 变色、按下位移/缩放；主按钮带 2px 底部阴影模拟"按压"；
- **选中态**：列表左侧竖条生长；Tab 用滑动指示块；
- **浮层**：用户菜单 / 导出菜单 / 证据抽屉共用（opacity+位移淡入、Esc/遮罩关闭、✕ 悬停旋转变红）；
- **即时反馈**：全局 Toast（约 1.9s）覆盖复制/反馈/导出/搜索等所有动作；👍👎 可切换选中态并计数；
- **AI 过程感**：生成中打字三点动画 + 轨迹步骤（路由→检索→合成→校验）；回答完成状态绿点脉冲；
- **引用溯源**：引用编号 hover 出证据气泡 tooltip，点击弹证据抽屉（含高亮/置信度/跳转原文）；
- **键盘**：Ctrl+K 聚焦全局搜索、Esc 关抽屉、Enter 发送 / Shift+Enter 换行、输入框高度自适应；
- **可访问性**：`:focus-visible` 2px 焦点环；滚动条细样式。

> 后端同学参考：以上交互全部为纯 CSS/JS 实现，无外部依赖；正式开发时在 Next.js 中以全局 CSS 变量 + 共享组件（Button/Card/Toast/Drawer/Vote）落地，保证 10 页一致。
