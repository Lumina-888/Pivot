# 发布回滚 Runbook（未演练）

> **状态**：程序草稿。`GATE-P0-008` **未验证**。

## 发布顺序（目标）

1. 备份当前数据与配置；
2. 检出固定版本 tag（模块 tag / 波次 tag）；
3. 执行迁移（可前进/回滚说明以 M03 为准）；
4. 等待依赖 health/ready；
5. 冒烟：登录 → 上传/已有 ready 文档 → 检索 → 问答 → 导出；
6. 失败则回滚应用版本，必要时回滚迁移，再重复健康检查。

## 本波次限制

- 无 FastAPI，冒烟只能跑分组单元/契约与 Fake 领域链路；
- 无自动升级通道；
- CI 失败不得靠跳过授权或合并冲突来修绿。
